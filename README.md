# SerxDev · Portfolio personal

Web publicada: https://serxdev.org

Copia de la versión 12 publicada el 28 de octubre de 2026, preparada para revisión en la asignatura de Lenguaje de Marcas del ciclo DAM.

## Qué contiene

- `index.html`: HTML, CSS dentro de `<style>` y JavaScript dentro de `<script>`, tal como están en la web publicada.
- `assets/`: las imágenes originales utilizadas en el sitio.

Se conserva la implementación publicada sin refactorizar, para que la revisión corresponda al trabajo que se está mostrando.

## Cómo verla en local

Abre `index.html` en el navegador. No requiere instalar dependencias ni ejecutar un proceso de compilación.

## Estructura actual

- Cabecera con presentación, fotografía y enlaces de contacto.
- Cuatro secciones: Sobre mí, Experiencia, Formación y Portfolio.
- Navegación mediante pestañas que muestran u ocultan paneles con JavaScript, sin cargar otro documento.
- Carruseles de imágenes con controles y pausa.
- Estilos adaptables mediante media queries y soporte para movimiento reducido.

## Aspectos para revisar en clase

- Semántica y organización del HTML.
- Accesibilidad de la navegación por pestañas y de los carruseles.
- Organización y legibilidad del CSS y JavaScript integrados en el HTML.
- Diseño adaptable, rendimiento y carga de imágenes.
- SEO, metadatos y ventajas o límites de la estructura de un solo documento.

Estos puntos son propuestas para una revisión; no equivalen a una auditoría superada.
