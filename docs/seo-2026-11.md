# SEO y Search Console — noviembre de 2026

Registro de las tareas de SEO técnico y conexión de Search Console para [serxdev.org](https://serxdev.org/). Esta página documenta el estado observado; no modifica la configuración del dominio ni sustituye una nueva publicación del sitio.

## Cambios SEO publicados

En la actualización SEO publicada en el sitio se incorporaron:

- Título y descripción orientados al nombre profesional, la producción musical y el desarrollo de software de audio.
- URL canónica y metadatos Open Graph.
- Datos estructurados `Person` en JSON-LD.
- `robots.txt` y `sitemap.xml`.
- Directivas para rastreadores: acceso permitido a `OAI-SearchBot` y bloqueado a `GPTBot`.

La versión posterior incluyó el archivo HTML de verificación solicitado por Google Search Console en la raíz del dominio. Google confirmó la propiedad como **verificada automáticamente mediante archivo HTML** el 12 de noviembre de 2026. El archivo debe permanecer publicado para conservar este método de verificación; su token no se copia en esta documentación.

## Search Console

- Propiedad verificada: URL-prefix `https://serxdev.org/`.
- La misma propiedad quedó seleccionada en OpenSEO para consultar Search Console.
- Al revisar el panel, Google mostraba **«Se están procesando los datos; vuelve a comprobar esta sección mañana»**.
- Las consultas de rendimiento disponibles en OpenSEO devolvieron cero filas para los periodos consultados. Por ahora no hay datos de clics, impresiones ni consultas que analizar. Esto no permite concluir que la web no esté indexada.

## Revisión técnica registrada

La revisión técnica previa de OpenSEO encontró:

- La página principal respondió con estado HTTP 200 y era rastreable e indexable.
- La URL aparecía en el sitemap.
- Las 29 imágenes revisadas tenían texto alternativo.
- El título se señaló como aviso informativo por su longitud.

Estos resultados describen la revisión realizada en ese momento; no son una garantía permanente ni sustituyen las comprobaciones posteriores en Search Console.

## Próximas comprobaciones

1. Volver a Search Console cuando termine el procesamiento inicial.
2. Inspeccionar `https://serxdev.org/` y, si Google lo permite, solicitar la indexación.
3. Revisar el informe de indexación y el rendimiento cuando haya datos disponibles.
4. Comprobar que el sitemap se puede leer desde Search Console.
5. Revisar por separado Bing Webmaster Tools si se quiere medir la visibilidad en Bing. No se registra aquí una conexión a Bing ni un envío por IndexNow.

## Relación con el código del repositorio

Este registro documenta acciones hechas en la configuración/publicación del sitio y en Search Console. No implica que cada archivo de SEO publicado (por ejemplo, `robots.txt`, `sitemap.xml` o el archivo de verificación) esté sincronizado con la rama `main`. Antes de usar el repositorio para otra publicación, comprobar el contenido desplegado y sincronizar los archivos que correspondan. No publicar un token de verificación en documentación, historial de commits o capturas.

## Código fuente preparado para revisión

La rama `seo/head-metadata` incorpora una propuesta para que el repositorio incluya las etiquetas del `<head>`, los datos estructurados `Person`, `robots.txt` y `sitemap.xml`. Esta rama está preparada para revisión y **no se ha fusionado con `main` ni desplegado**. La existencia de estos archivos en la rama no confirma por sí sola que Google los haya rastreado.
